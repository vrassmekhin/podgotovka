# 🎓 Подготовка

Удобное приложение-сайт для подготовки к контрольному зачёту по вузовскому
предмету. Объединяет **изучение**, **мотивацию**, **закрепление прогресса** и
**контроль заполненности** в одном месте.

> Принцип: вы загружаете **вопросы**, а учите **ответы**. Для предмета
> «История России» ответы уже написаны и готовы к изучению.

## Как запустить

Это статический сайт без сборки. Достаточно открыть **`index.html`** двойным
кликом в любом браузере — приложение полностью работает офлайн.

Прогресс, заметки и добавленные предметы хранятся в браузере (localStorage), на
том устройстве, где вы занимаетесь.

> Для публикации в интернете подойдёт любой статический хостинг
> (например, GitHub Pages: Settings → Pages → ветка с этим репозиторием).

## Установка как приложение на iPhone/iPad (PWA)

Приложение можно поставить на домашний экран — оно откроется в полноэкранном
режиме, со своей иконкой 🎓 и будет работать офлайн.

> Важно: для установки сайт должен быть открыт **по адресу https** (например,
> через GitHub Pages), а **не** как локальный файл. Service worker и установка
> на file:// не работают.

Шаги на iOS (в браузере **Safari**):
1. Откройте опубликованный адрес сайта (см. раздел «Публикация» ниже).
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран „Домой“»** → **«Добавить»**.
4. На домашнем экране появится иконка **«Подготовка»** — запускается как
   обычное приложение, без адресной строки.

На Android (Chrome) — меню ⋮ → **«Установить приложение»**.

## Публикация (чтобы появился https-адрес)

Откройте репозиторий → **Settings → Pages** → Source: **Deploy from a branch**
→ выберите ветку и папку `/(root)` → **Save**. Через ~минуту сайт будет
доступен по адресу вида `https://<пользователь>.github.io/podgotovka/` —
именно его открывайте в Safari для установки.

## Возможности

- **Изучение** — режим карточек: вопрос → «Показать ответ» → отметка
  «Выучил» / «Повторить позже». Ответы оформлены конспектом (даты, причины,
  итоги, списки) для быстрого запоминания.
- **Мотивация** — серия дней подряд (🔥 streak), достижения, ободряющие фразы,
  экран «предмет пройден».
- **Прогресс** — кольца и полосы прогресса по каждому предмету и в целом;
  статусы вопросов (новый / учу / готово) сохраняются автоматически.
- **Контроль заполненности** — приложение показывает, на какие вопросы ещё
  **нет ответа** (красная метка и баннер), чтобы ничего не пропустить.
- **Поиск и фильтры** по вопросам и статусам.
- **Светлая / тёмная тема**.

## Добавление новых предметов и вопросов

Перестраивать приложение **не нужно**. Есть два способа:

### 1. Прямо в интерфейсе (без правки файлов)
«＋ Добавить предмет» → вписать название → вставить вопросы (по одному в
строке; строки вида `Билет № N` станут заголовками разделов) → заполнить
ответы во встроенном редакторе. Можно также импортировать/экспортировать
предмет в JSON. Такие предметы хранятся в браузере.

### 2. Как встроенный предмет (файлом)
1. Создайте `data/<имя-предмета>.js`:
   ```js
   Podgotovka.register({
     id: "filosofiya",
     title: "Философия",
     emoji: "🧠",
     tickets: [
       { title: "Билет № 1", questions: [
         { q: "Текст вопроса", a: "Текст ответа для изучения" }
       ] }
     ]
   });
   ```
2. Подключите файл одной строкой в `index.html`:
   ```html
   <script src="data/filosofiya.js"></script>
   ```
Код самого приложения при этом не меняется — реестр предметов
(`data/registry.js`) является точкой расширения.

## Структура проекта

```
index.html              — точка входа, подключает данные и приложение
assets/styles.css       — оформление (светлая/тёмная тема, адаптив)
assets/app.js           — вся логика приложения (vanilla JS)
data/registry.js        — реестр предметов (точка расширения)
data/history-rossii.js  — предмет «История России»: 19 билетов, 38 вопросов с ответами
```

## Поддерживаемая разметка в ответах

- `**жирный текст**`
- строки, начинающиеся с `- ` или `• `, превращаются в список;
- пустая строка разделяет абзацы.
