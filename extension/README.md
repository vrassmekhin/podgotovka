# 🎓 Подготовка — расширение «Разбор вопросов»

Браузерное расширение (Manifest V3) для **подготовки к тестам**. Выделите на
любой странице вопрос с вариантами ответа — выедет панель, где Claude
**по пунктам разберёт каждый вариант** (верный/неверный и почему) и подведёт
к правильному ответу. Цель — понять материал, а не просто увидеть ответ.

## Установка (Chrome / Edge / любой Chromium)

1. Откройте `chrome://extensions`.
2. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
3. **«Загрузить распакованное расширение»** (Load unpacked) → выберите папку
   `extension/`.
4. Нажмите на иконку 🎓 → **«Настройки и API-ключ»** → вставьте ключ
   Claude API (получить: <https://console.anthropic.com/settings/keys>) →
   **«Сохранить»**. Можно нажать **«Проверить ключ»**.

> Firefox: загрузите через `about:debugging` → «This Firefox» → «Load Temporary
> Add-on» → выберите `manifest.json`.

## Как пользоваться

1. Выделите мышью текст вопроса (желательно вместе с вариантами ответа).
2. Нажмите всплывшую кнопку **«🎓 Разобрать вопрос»** — или правый клик →
   **«Разобрать вопрос (Подготовка)»**.
3. В правом верхнем углу появится панель с потоковым разбором. Её можно
   перетаскивать за заголовок, скопировать (⧉), повторить (↻) или закрыть (✕).

## Настройки

| Параметр | Описание |
| --- | --- |
| **API-ключ** | Ключ Claude API. Хранится только локально (`chrome.storage.local`). |
| **Модель** | Sonnet 4.6 (баланс), Opus 4.8 (умнее), Haiku 4.5 (быстрее/дешевле). |
| **Длина ответа** | Лимит токенов разбора (300–4000). |

## Как устроено

```
manifest.json   — MV3-манифест (background, content-script, popup, options)
background.js   — контекстное меню + потоковый вызов api.anthropic.com (SSE)
content.js      — плавающая кнопка и панель разбора (изолированы в Shadow DOM)
popup.html/js   — статус ключа и быстрый вход в настройки
options.html/js — ключ, выбор модели, длина ответа, проверка ключа
icons/          — иконки расширения
```

Запрос к API уходит **напрямую из браузера** с заголовком
`anthropic-dangerous-direct-browser-access`, поэтому ключ никуда, кроме
Anthropic, не передаётся. Расходуется ваш баланс Anthropic.

## ⚠️ Честное использование

Инструмент создан для **обучения и подготовки**: он объясняет ход рассуждения,
чтобы вы разобрались в теме. Использование во время реальных
экзаменов/зачётов может нарушать правила учебного заведения или платформы.
